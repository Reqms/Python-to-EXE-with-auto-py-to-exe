# Python to EXE with auto-py-to-exe

**Guide to convert .py → .exe (Windows) / Гайд по конвертации Python в exe через auto-py-to-exe.** 

---

## Installation

Open the terminal and run: pip install auto-py-to-exe

**If it doesn't install,** try: python -m pip install auto-py-to-exe

---

## Run

After installation, enter in the terminal:
auto-py-to-exe

A browser window will open.

---

## How to use

1. Select your `.py` file in `Script Location`
2. `One File` → select `One File`
3. `Console Window` → select the desired mode:
   - `Console Based` — for console programs
   - `Window Based` — for GUI applications (Tkinter, PyQt)
4. Click the **CONVERT** button

The finished `.exe` will appear in the `output/` folder

## Как использовать

1. Выберите ваш `.py` файл в поле `Script Location`
2. `One File` → выберите `One File` (один exe-файл)
3. `Console Window` → выберите нужный режим:
   - `Console Based` — для консольных программ
   - `Window Based` — для приложений с окном (Tkinter, PyQt)
4. Нажмите кнопку **CONVERT**

Готовый `.exe` появится в папке `output/`
