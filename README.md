# Python to EXE with auto-py-to-exe

**English / Русский:** Guide to convert .py → .exe (Windows) / Гайд по конвертации Python в exe через auto-py-to-exe.

---

##  Установка

Откройте терминал и выполните команду: pip install auto-py-to-exe
text **Если не устанавливается,** попробуйте: python -m pip install auto-py-to-exe
text

---

##  Запуск

После установки введите в терминале:
auto-py-to-exe

Откроется окно в браузере.

---

##  Как использовать

1. Выберите ваш `.py` файл в поле `Script Location`
2. `One File` → выберите `One File` (один exe-файл)
3. `Console Window` → выберите нужный режим:
   - `Console Based` — для консольных программ
   - `Window Based` — для приложений с окном (Tkinter, PyQt)
4. Нажмите кнопку **CONVERT**

Готовый `.exe` появится в папке `output/`
